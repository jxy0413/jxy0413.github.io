# Xiangyu Jia — Academic Homepage

Static GitHub Pages site for Xiangyu Jia (贾相宇), built with plain HTML, CSS, and JavaScript.

The site is designed as the academic counterpart to the [`jxy0413/jxy0413`](https://github.com/jxy0413/jxy0413) profile README. It includes bilingual navigation, a light/dark theme toggle, selected publications, news, education, experience, and contact links.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
